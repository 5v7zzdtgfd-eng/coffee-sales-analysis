# Анализ продаж кофейни (учебный кейс)

## Задача
Разобрать данные продаж кофейни, найти закономерности и сформулировать
практические рекомендации для владельца.

## Данные
7 174 транзакции за март–октябрь 2026 года. Столбцы: дата, час покупки,
способ оплаты (карта/наличные), сумма, вид напитка, время суток,
день недели, месяц.

## Ключевые выводы
1. Латте — лидер по числу заказов и выручке (35% выручки);
   латте + капучино дают 62% кассы.
2. 77% оплат картой, 23% наличными.
3. Пик продаж — 8:00–10:00: утро приносит 56% всей выручки, вечер — 12%.
4. Выходные приносят на ~38% больше выручки, чем будни
   (суббота и воскресенье — по 250–256 тыс. ₽ против 178–188 тыс. в будни).
5. Выручка стабильно растёт: с 140 тыс. ₽ в марте до 223 тыс. ₽ в октябре.

## Рекомендации для владельца
- Держать вторую кассу и заготавливать молоко под утренний пик (8:00–10:00).
- Вечером стимулировать допродажи: десерты к эспрессо и кортадо
  (низкий средний чек).
- Различать смены и закупки по дням недели: выходные стабильно сильнее будней.
- Рост выручки с весны к осени — учитывать при закупке сырья на зиму.

## Как это сделано
- Генерация и анализ данных: Python, pandas.
- Графики: matplotlib.
- Результаты сведены в Excel-файл с листом «Вопросы-Ответы».
